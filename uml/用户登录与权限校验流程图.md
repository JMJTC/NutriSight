@startuml
title 用户登录与权限校验流程图

|用户|
start
:输入用户名和密码;
:提交登录请求;

|Vue3前端|
:调用登录接口;

|FastAPI后端|
:接收登录请求;
:校验参数完整性;

|数据库|
:查询用户信息;

|FastAPI后端|
if (账号是否存在?) then (存在)
  :校验密码;
else (不存在)
  :返回账号不存在;
  stop
endif

if (密码是否正确?) then (正确)
  :生成 JWT Token;
  :返回用户信息和权限数据;
else (错误)
  :返回密码错误;
  stop
endif

|Vue3前端|
:保存 Token;
:加载菜单和路由权限;

|用户|
:进入系统首页;

|FastAPI后端|
:用户访问受保护接口;
if (Token 是否有效?) then (有效)
  :校验角色和接口权限;
else (无效)
  :拒绝访问并要求重新登录;
  stop
endif

if (是否具备权限?) then (是)
  :执行接口业务逻辑;
else (否)
  :返回无权限提示;
endif

stop
@enduml
