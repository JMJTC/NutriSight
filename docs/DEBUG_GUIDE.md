## 前端调试步骤

### 1. 完全刷新浏览器
```
按快捷键: Ctrl + Shift + R (Windows/Linux) 或 Cmd + Shift + R (Mac)
```

### 2. 打开开发者工具
```
按快捷键: F12
```

### 3. 切换到 Console 标签
在浏览器开发者工具中找到 "Console" 标签，点击它

### 4. 重新上传图片识别

### 5. 查看以下信息在页面上显示的调试面板：
- `原始图片路径`: 应该显示如 `/static/uploads/xxxxx.jpg`
- `标注图片路径`: 可能为空如果没有检测到食物
- `最终图片URL`: 应该显示如 `http://127.0.0.1:9999/static/uploads/xxxxx.jpg`

### 6. 查看浏览器控制台输出：
- 应该能看到 "Recognition result:" 后面跟完整的返回对象
- 如果图片加载失败，应该看到 "Image load failed:" 错误

## 常见问题

**如果你看不到调试信息面板：**
- 可能是前端代码还没有刷新，试试再按一次 Ctrl+Shift+R

**如果你看不到图片加载错误但图片也没显示：**
- 检查页面 HTML 的 img 标签的 src 属性是否为空
- 在控制台中输入查看: `console.log(window.location)`

**如果 URL 看起来不对：**
- 记下你见到的完整路径信息，我们可以调整构造逻辑
